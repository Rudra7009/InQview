# InQview
Mock, Master,  Succeed.

InQview is a cutting-edge web platform designed to revolutionize how students prepare for job interviews. By leveraging Artificial Intelligence (AI) and Natural Language Processing (NLP), InQview provides a personalized and adaptive interview preparation experience.

## Features

- **Custom Question Generation**:  
  Utilizes NLP algorithms to analyze resumes and generate tailored interview questions based on skills, roles, and achievements.

- **Realistic Mock Interviews**:  
  Provides an immersive interview environment with dynamic scenarios, helping users build confidence for real-world interviews.

- **Comprehensive Feedback**:  
  Offers detailed analytics and personalized suggestions to identify skill gaps and enhance interview performance.

- **Scalability and Accessibility**:  
  A cloud-based platform that supports users across different locations and devices.

- **Privacy Protection**:  
  Implements strict data security protocols to ensure sensitive resume information is safeguarded.

## Proposed Solution

InQview bridges the gap between traditional interview preparation methods and the demands of modern recruitment processes by:

1. **Custom Question Generation:**  
   Using advanced NLP to craft questions from resume data such as skills, roles, and achievements.

2. **Realistic Mock Interviews:**  
   Creating an immersive interview setting with dynamic scenarios to simulate real interview situations.

3. **Comprehensive Feedback:**  
   Providing detailed analytics and actionable feedback to help users improve their responses.

4. **Scalability and Accessibility:**  
   Leveraging a cloud-based architecture to deliver a seamless experience across multiple devices and locations.

5. **Privacy Protection:**  
   Enforcing strict data security standards to protect users' sensitive information.

## Technologies Used

- **Frontend:**  
  - **React.js:**  
    For building a responsive and interactive user interface.

- **Backend:**  
  - **Node.js with Express:**  
    For managing server-side processing and API integrations.

- **Database:**  
  - **MongoDB:**  
    For securely storing user data, resumes, and interview history.

- **Natural Language Processing:**  
  - **AWS Bedrock:**  
    To generate domain-relevant, skill-based mock interview questions.

- **Text Extraction:**  
  - **Amazon Textract:**  
    Facilitates the extraction of structured data from resume PDFs and images.

- **Cloud Hosting:**  
  - **AWS:**  
    Provides scalability and performance reliability to support the platform.


## Usage

1. **Upload Your Resume:**  
   Log in to InQview and upload your resume (PDF or image). The platform will automatically extract text using Amazon Textract.

2. **Generate Custom Mock Questions:**  
   AI-powered algorithms analyze your resume to create personalized interview questions based on your skills, roles, and experiences.

3. **Practice with Realistic Mock Interviews:**  
   Engage in simulated interviews that mimic real-world scenarios, complete with dynamic questions and environments.

4. **Analyze Feedback:**  
   After each mock interview, review detailed analytics and personalized feedback to pinpoint areas for improvement.
